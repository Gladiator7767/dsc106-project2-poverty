# DSC 106 Project 2: What counts as progress against poverty?

[View the report](https://gladiator7767.github.io/dsc106-project2-poverty/)

Team review version of the Project 2 Final report. The team is reviewing the writeup before the course submission; this repository does not indicate that the assignment has been submitted.

## Proposition

Between 1990 and 2018, Sub-Saharan Africa made substantial progress against extreme poverty.

The report presents one visualization for the proposition and one against it, with five design decisions per visualization, a final reflection, and data and methods. It uses the course-provided historical World Bank archive, the SSF region, and the $1.90/day poverty line in 2011 PPP.

## Files

- `index.html`: complete English report and team information.
- `style.css`: report layout and responsive styles.
- `assets/`: both charts in SVG and PNG formats.
- `data/`: the 29 annual records and source/method metadata.
- `.nojekyll`: serves this plain HTML site directly through GitHub Pages.

GitHub Pages publishes `main` from the repository root. Relative asset paths allow the report to run under this repository's project URL. No build step is needed.
